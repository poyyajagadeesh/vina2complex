# AutoDock Vina Pose Extractor & Complex Builder

A lightweight Python utility to extract individual ligand poses from AutoDock Vina docking results and generate protein–ligand complex structures for downstream molecular modeling and molecular dynamics simulations.

The script is designed specifically for docking results generated using the **AutoDock Vina** engine through the **PyRx** graphical interface, although it is compatible with any standard multi-pose PDBQT output produced by AutoDock Vina or compatible software.

---

## Features

- Extracts all ligand poses from a multi-pose PDBQT file
- Converts ligand PDBQT files to standard PDB format
- Converts receptor PDBQT to clean PDB format
- Automatically removes common non-standard residues and cofactors from the receptor
- Generates separate protein–ligand complex PDB files for every docking pose
- Creates a multi-model PDB containing all docked poses
- Produces a CSV summary containing:
  - Binding affinity
  - RMSD values
  - Number of ligand atoms
- Uses only the Python Standard Library (no additional packages required)

---

## Input

The script requires two files:

- **Receptor PDBQT**
  - Generated from AutoDock Tools or PyRx

- **Ligand docking output (PDBQT)**
  - Multi-pose docking result generated by AutoDock Vina
  - Typically exported from the PyRx AutoDock Vina module

Example:

```
receptor.pdbqt
ligand_out.pdbqt
```

## Output

After execution, the following directory structure is created:

```
ligand_out_analysis/
│
├── poses/
│   ├── pose_1.pdbqt
│   ├── pose_1.pdb
│   ├── pose_2.pdbqt
│   ├── pose_2.pdb
│   └── ...
│
├── complexes/
│   ├── complex_pose_1.pdb
│   ├── complex_pose_2.pdb
│   ├── ...
│   └── all_poses.pdb
│
└── poses_summary.csv
```

## Installation

Clone the repository

```bash
git clone https://github.com/<username>/extract_poses_and_complexes.git

cd extract_poses_and_complexes
```

No external Python packages are required.

Requirements:

- Python 3.8+
- Standard Python Library

---

## Usage

```bash
python extract_poses_and_complexes.py \
    -r receptor.pdbqt \
    -l ligand_out.pdbqt
```

Optional output directory:

```bash
python extract_poses_and_complexes.py \
    -r receptor.pdbqt \
    -l ligand_out.pdbqt \
    -o results
```

        │

 Ligand PDB Files

## Compatibility

Tested with docking results generated using:

- AutoDock Vina
- PyRx (AutoDock Vina module)

The script also supports standard multi-model PDBQT files produced by software compatible with the AutoDock Vina output format.
